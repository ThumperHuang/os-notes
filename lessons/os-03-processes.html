Ch3 行程 Processes

來源：03_OS_Processes_v1.0.pdf

學習目標

  • 分辨 Program 與 Process
  • 畫出五種行程狀態與轉換
  • 說明 PCB 內容與排程器的種類

直覺說明

Program 像一份食譜，是寫在紙上的靜態檔案。Process 像廚師照著食譜實際在煮菜，有進度、有用到的鍋碗瓢盆。同一份食譜可以讓兩位廚師同時照做，它們是兩個獨立的 Process。

核心概念

ProgramProcess
性質被動（passive）主動（active）
位置磁碟上的可執行檔記憶體中執行的程式
擁有指令PC、暫存器、資源

Process 在記憶體中的配置

  • Text：程式碼
  • Data：靜態與全域變數
  • Heap：動態配置（malloc）
  • Stack：函式呼叫的 activation record（參數、區域變數、返回位址）

同一程式開兩個 Process 時，Text 相同，但 Heap 和 Stack 各自獨立。

五種狀態

狀態意義
New正在建立
Ready在記憶體等 CPU（有意願跑，沒在跑）
RunningCPU 正在執行指令
Waiting等待事件，如 I/O（沒意願跑）
Terminated已結束

Running 離開 CPU 的情況：被搶先（→ Ready）、等待 I/O（→ Waiting）、結束（→ Terminated）。

PCB（Process Control Block）

Kernel 為每個 Process 維護一個 PCB，內容包含：Process state、Program counter、CPU registers、CPU scheduling information、Memory-management information、Accounting information、I/O status information。Linux 中以 task_struct 實作。

排程器

種類工作頻率
Long-term（Job scheduler）決定哪些 Process 進入 ready queue，控制 degree of multiprogramming低（秒、分鐘）
Short-term（CPU scheduler）選下一個要跑的 Process高（毫秒），必須快
  • I/O-bound：大量短 CPU burst
  • CPU-bound：少量長 CPU burst

程式或範例

#include <stdio.h>
#include <sys/types.h>
#include <sys/wait.h>
#include <unistd.h>

int main(void) {
    pid_t pid = fork();            /* 建立子行程 */
    if (pid < 0) {
        perror("fork");
        return 1;
    } else if (pid == 0) {
        printf("child: pid=%d\n", getpid());
    } else {
        wait(NULL);                /* 等子行程結束 */
        printf("parent: child done\n");
    }
    return 0;
}

預期輸出（pid 數字依系統而異）：

child: pid=12346
parent: child done

考試重點

  • Program（passive）與 Process（active）的差別。
  • 五種狀態圖，以及 Ready 與 Waiting 的差異。
  • PCB 包含哪些欄位。
  • Long-term 與 Short-term scheduler 的差異。
  • Stack 與 Heap 的用途，且成長方向相反。

常見錯誤

  • 把 Waiting 和 Ready 混淆。Ready 是在等 CPU，Waiting 是在等事件（如 I/O）。
  • 以為兩個執行同一程式的 Process 共用 Heap 和 Stack。實際上只有 Text 相同。

練習題

題目 1：Process 等待 I/O 完成後會進入哪個狀態？

Ready。I/O 完成後它有意願跑，但需重新排隊等 CPU。

題目 2：Degree of multiprogramming 由哪個排程器控制？

Long-term scheduler。
